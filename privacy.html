개인정보처리방침 — 늦은 답장 업로드

시행일: 2026년 11월 2일

1. 무엇을 하는 앱인가

「늦은 답장 업로드」는 유튜브 채널 「늦은 답장 (Late Reply)」의 운영자가 자기 채널에 영상을 올리기 위해 직접 만든 개인용 도구입니다. 운영자 본인의 Google 계정으로만 사용합니다.

2. 사용하는 Google 사용자 데이터

  • YouTube Data API 권한(https://www.googleapis.com/auth/youtube)으로 운영자 채널에 영상을 업로드하고, 썸네일과 재생목록을 설정하며, 업로드한 영상의 공개 상태를 확인합니다.
  • 운영자 채널이 맞는지 확인하려고 채널 ID와 채널 이름을 읽습니다.
  • 다른 사람의 데이터는 읽거나 모으지 않습니다.

3. 저장과 공유

  • 인증 토큰은 운영자의 컴퓨터에만 저장되며, 외부 서버로 보내지 않습니다.
  • Google 사용자 데이터를 제3자에게 팔거나 넘기지 않고, 광고에 쓰지 않습니다.
  • 이 앱의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 접근 취소

언제든 Google 계정의 서드 파티 연결에서 이 앱의 접근 권한을 취소할 수 있습니다. 취소하면 운영자 컴퓨터의 토큰도 더 이상 쓸 수 없습니다.

5. 문의

유튜브 채널 @late-reply-band로 문의해 주세요.

English summary

This personal tool uses the YouTube Data API only to upload videos, set thumbnails and playlists, and check upload status on the owner's own channel. Tokens are stored only on the owner's computer and are never sent to any server or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
